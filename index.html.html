# ⚡ TeraPulse — Full-Quality Terabox Direct Link Extractor

A zero-dependency, single-file static web client (`index.html`) designed for **GitHub Pages** that extracts untouched, full-quality Terabox `dlink` CDN URLs for multi-threaded download managers (**1DM**, **IDM**, **FDM**, and **aria2c**).

## ✨ Features
- **3 Connection Modes**:
  1. **CORS Relay + Cookie**: Fetch metadata directly from Terabox endpoints using a CORS proxy prefix and your local `ndus` session cookie.
  2. **Custom Worker API**: Connect to your own private Cloudflare Worker or FastAPI backend via `POST { url, ndus }`.
  3. **Demo / Offline Preview Mode**: Test single 4K files and multi-file folders immediately without credentials.
- **Original Source Quality**: Preserves original video resolution, bitrate, and multi-audio tracks without web-player transcoding.
- **Multi-File Folder Support**: Lists all files in shared folders with individual action buttons plus **Copy All Links**.
- **16-Thread `aria2c` Command Generator**: Generates ready-to-paste terminal commands with required `User-Agent` and `Referer` headers.

## 🚀 Deploy to GitHub Pages
1. Fork or upload `index.html` to a GitHub repository.
2. Navigate to **Settings → Pages**.
3. Set **Source** to `Deploy from a branch`, choose `main` and `/ (root)`, then click **Save**.
4. Open your live GitHub Pages URL and configure your connection mode under **Live Connection Settings**.

3 Optional Free Cloudflare Worker (For Mode B)

Because public CORS proxies strip sensitive Cookie headers, deploying this free Cloudflare Worker gives your GitHub Pages site reliable live extraction with Mode B: 

export default {
  async fetch(request, env) {
    const cors = {
      "Access-Control-Allow-Origin": "*",
      "Access-Control-Allow-Methods": "POST, GET, OPTIONS",
      "Access-Control-Allow-Headers": "Content-Type",
      "Content-Type": "application/json"
    };
    if (request.method === "OPTIONS") return new Response(null, { headers: cors });

    let shareUrl = "", ndus = env.TERABOX_NDUS || "", pwd = "";
    if (request.method === "POST") {
      const body = await request.json().catch(() => ({}));
      shareUrl = body.url || "";
      if (body.ndus) ndus = body.ndus;
      pwd = body.pwd || "";
    } else {
      const { searchParams } = new URL(request.url);
      shareUrl = searchParams.get("url") || "";
    }

    const match = shareUrl.match(/\/s\/([a-zA-Z0-9_-]+)/) || shareUrl.match(/surl=([a-zA-Z0-9_-]+)/);
    const shorturl = match ? match[1].replace(/^1/, "") : "";
    if (!shorturl) return new Response(JSON.stringify({ error: "Invalid Terabox share link" }), { status: 400, headers: cors });

    const headers = {
      "Cookie": `ndus=${ndus};`,
      "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36",
      "Referer": "https://www.terabox.com/"
    };

    const infoRes = await fetch(`https://www.terabox.com/api/shorturlinfo?app_id=250528&shorturl=${shorturl}&root=1&pwd=${pwd}`, { headers });
    const data = await infoRes.json();
    if (data.errno !== 0 || !data.list?.length) {
      return new Response(JSON.stringify({ error: `Terabox API errno ${data.errno} (Check ndus cookie or share link)` }), { status: 400, headers: cors });
    }

    const files = data.list.map(f => ({
      fs_id: f.fs_id,
      server_filename: f.server_filename,
      size: f.size,
      dlink: f.dlink,
      thumbs: f.thumbs || {}
    }));
    return new Response(JSON.stringify({ files }), { headers: cors });
  }
};
